# 취업 면접 연습실

아이디·비밀번호 가입, 8개 질문 연습, 답변 버전 및 학습 기록 저장, 준비된 피드백 예시, 인쇄를 제공합니다. Supabase Auth가 비밀번호를 관리하며 PostgreSQL RLS가 본인 기록만 허용합니다. 브라우저에는 publishable key만 포함됩니다.

`npm ci` 후 `npm run build`. 배포 폴더는 public/입니다. Supabase의 이메일·비밀번호 인증을 사용하되 화면의 아이디는 정규화하여 `아이디@students.interview.invalid`로 매핑합니다. 이메일은 받거나 발송하지 않습니다. 이메일 확인을 사용하지 않는 전용 프로젝트로 구성합니다.

비밀번호 분실 시 담당 교사에게 문의하도록 안내합니다. 운영자는 Supabase Authentication 사용자 관리에서 아이디에 해당하는 사용자를 찾고 본인 확인 후 비밀번호를 재설정해야 합니다. 관리자 키를 웹 앱에 넣지 마세요. 학생이 직접 교사 역할을 선택하거나 타 학생 기록을 열 수 있는 기능은 제공하지 않습니다.

원래 명세서의 역할 체험을 실제 인증과 서버 저장으로 확장한 기본 버전입니다. 실제 AI 분석·최신 기출·교사별 담당 배정 화면은 구현 범위에 포함되지 않습니다. 실제 학생 이름·학교명·연락처는 수집하지 않습니다.

# 수학의 여백

DESIGN.md의 종이색 배경, 청록색 선택 상태, 얇은 테두리, 평평한 카드 디자인을 반영한 한국어 수학 미니 게임입니다. 외부 라이브러리, 외부 폰트, 계정이나 서버 저장소를 사용하지 않습니다.

## 로컬 실행

Node.js가 설치된 환경에서 이 폴더를 터미널로 열고 실행합니다.

```powershell
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 서버는 로컬 루프백 주소에만 연결됩니다. 종료하려면 터미널에서 Ctrl+C를 누르세요. 포트가 사용 중이면 `$env:PORT=4174` 설정 후 실행할 수 있습니다.

별도 설치 없이 `dist/index.html`을 브라우저로 열어도 게임을 즐길 수 있습니다. 기록 저장은 브라우저 환경과 파일/접속 주소에 따라 분리될 수 있으므로 로컬 서버 사용을 권장합니다.

## 기능

- 60초 사칙연산, 10문제 빈칸 찾기, 10문제 크기 비교
- 세 가지 난이도, 즉시 정답 안내, 연속 정답 및 정확도
- 최근 50판 브라우저 내 기록 저장
- 모바일 레이아웃, 키보드 숫자 선택

공개 배포나 외부 서비스 등록을 하지 않은 로컬 전용 프로젝트입니다.

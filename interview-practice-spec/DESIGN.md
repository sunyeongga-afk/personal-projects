# 취업 면접 연습실 디자인 초안

출처: 사용자가 선택한 ‘단정한 학교 서비스형’, 학생 휴대폰·교사 PC. 기존 디자인 문서는 미제공. 참고 앱 내부는 인증 제한으로 확인하지 못했으므로 자체 화면을 설계한다.

## 목표와 원칙
- 학생: 한 번에 한 질문과 명확한 다음 행동. 질문 → 답변 → 피드백 순서로 배치한다.
- 교사: 담당 학생 목록 → 답변 상세 → 의견 작성 흐름. PC에서는 목록과 상세를 나란히 둘 수 있다.
- 모든 화면: ‘가상 데이터 체험 · 준비된 질문과 피드백 예시’ 표시. 피드백은 실제 답변 분석 결과처럼 표현하지 않는다.

## 시각 규칙
아래 수치는 구현 기본값에 대한 가정이다.
- 배경 #F8FAFC, 표면 #FFFFFF, 기본 글자 #0F172A, 보조 글자 #475569, 주색 #1D4ED8, 테두리 #CBD5E1.
- 오류 #B91C1C, 성공 #166534. 색상과 함께 아이콘·문장으로 상태를 표시한다.
- 시스템 한글 산세리프. 본문·입력 16px 이상, 본문 줄간격 1.6, 제목 24~32px.
- 간격 4/8/12/16/24/32px, 모바일 좌우 여백 16px, PC 최대 폭 1200px.
- 버튼·터치 영역 높이 최소 44px, 카드 반경 12px. 과한 그림자와 장식 이미지는 사용하지 않는다.

## 공통 요소
명시적인 레이블과 도움말이 있는 입력, 주 동작 파란 버튼, 보조 테두리 버튼, 질문 카드, 상태 배지, 저장 안내, 오류 메시지, 초기화 확인창을 사용한다. 질문과 피드백을 구분하고 피드백 제목은 ‘준비된 피드백 예시’로 고정한다.

## 반응형
768px 미만은 한 열. 학생 답변 입력창과 저장 버튼이 모바일 키보드에 가려지지 않게 한다. 1024px 이상에서 교사 목록·상세를 두 열로 구성할 수 있다. 모바일 교사 표는 카드로 바꾼다. 가로 넘침을 막고 고정 높이로 답변을 자르지 않는다.

## 상태
- 로딩: 실제 작업이 있을 때 짧은 진행 안내. 가짜 AI 분석 애니메이션 금지.
- 빈 화면: ‘아직 작성한 답변이 없습니다’와 연습 시작 동작.
- 오류: 원인과 복구 동작. 입력 내용 보존.
- 완료: ‘답변을 저장했습니다’ 등 구체 문장. 화면 읽기 도구에 상태 전달.
- 인쇄: 메뉴·버튼 숨김, 밝은 바탕과 진한 글자, 질문·답변·의견·데모 표시 유지. 페이지 경계에서 글자 잘림 점검.

## 접근성·금지 사항
키보드 조작, 가시 포커스, 입력 오류 연결, 일반 글자 대비 4.5:1 목표, 200% 확대를 검증한다. 장식 아이콘은 보조기술에서 숨기고 의미 있는 아이콘에는 이름을 제공한다. 색만으로 상태를 구별하지 않는다. 합격 확률·학생 순위·근거 없는 점수를 표시하지 않는다. 다크 모드·캐릭터·게임 보상은 첫 버전 범위 밖이다.

## 확인 목록
360/768/1280px 표시, 긴 자기소개서와 답변 줄바꿈, 키보드 이동, 확대, 저장 오류, 빈 기록, 교사 의견, 인쇄 미리보기, 모든 결과의 예시 표시를 확인한다.

# 교사 도구함

계산기, PDF 글자 수 세기, 외부 프로그램 링크 관리 도구입니다.

Node.js 24 이상에서 `npm start` 후 http://127.0.0.1:54321 을 여세요. `npm test`로 검증합니다. 서버는 로컬 PC에서만 실행합니다.

PDF는 브라우저 메모리에서 처리하며 업로드하거나 저장하지 않습니다. 외부 링크 목록은 브라우저 localStorage에 저장됩니다. 백업 파일과 링크에 비밀번호·토큰·개인정보를 넣지 마세요.

PDF.js와 포함 글꼴의 라이선스는 vendor/pdfjs 안에 보존되어 있습니다.
